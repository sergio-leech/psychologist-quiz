# Хто хоче стати психологом 🧠

15 складних питань з психології. Відповідайте правильно на кожне — і дійдете до головного призу.

## Технічно
- Самодостатній `index.html` (HTML + CSS + JavaScript), без бібліотек і бекенду.
- Звук через Web Audio API з перемикачем, конфеті на canvas, адаптивний дизайн.
