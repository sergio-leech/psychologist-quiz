# Хто хоче стати психологом 🧠

Гра-вікторина у стилі «Хто хоче стати мільйонером»: **15 нескладних і цікавих питань з психології**,
варіанти відповідей, перехід до наступного питання, сходи до призу, підказка 50:50, звукові ефекти та конфеті.

Головний приз — таємниця до самої перемоги. Відповіси правильно на всі 15 — зʼявиться вітальний попап із призом
і кнопкою **«Отримати»**, яка надсилає повідомлення в Telegram **@sergio_lee18**.

## Технічно
- Один самодостатній `index.html` (HTML + CSS + JavaScript), без бібліотек і без бекенду.
- Звук — через Web Audio API (без аудіофайлів), є перемикач 🔊/🔇.
- Конфеті — на canvas. Адаптивний дизайн (desktop / mobile).
